# Code of Conduct

MLXtra aims to be a practical, respectful open source project.

## Expected Behavior

- Be direct, constructive, and respectful.
- Assume technical disagreement is normal and resolve it with evidence.
- Keep issues and pull requests focused on the project.
- Credit prior work and upstream projects accurately.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Repeated off-topic disruption of issues, discussions, or reviews.
- Bad-faith security disclosures or public exploit details before maintainers
  have a reasonable chance to respond.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; decline
contributions; or block participants when needed to protect the project.

If you need to report conduct concerns, use the same private reporting path
described in `SECURITY.md` until a dedicated contact address exists.
