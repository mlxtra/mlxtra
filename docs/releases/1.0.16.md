# MLXtra 1.0.16

This release updates the local generation runtime to 0.1.10 and fixes issues
found while testing the curated model catalog.

- Upgrades the Python, MLX, vision, speech, image, and music dependencies, plus
  Swift Markdown and Sparkle.
- Makes Kokoro English speech available without a first-use language-data
  download and fixes speech initialization in long app bundle paths.
- Restores Magenta generation through its compatible isolated runtime and
  adapts Ideogram generation to the updated image library.
- Clears obsolete model-download warnings when a downloaded model is selected
  and prevents delayed automatic selection from replacing a newer selection.
- Improves runtime download recovery and model/settings status updates.

The app downloads runtime 0.1.10 as separate base and music components. The
runtime assets and the curated catalog require MLXtra 1.0.16 or later.

## Validation and known limitations

674 Swift tests and 120 Python unit tests passed, with 85.96% core Swift line
coverage. Sustained chat, cancellation during loading/streaming/music
generation, process recovery, native speech playback, signed update
installation, and notarization checks passed on an Apple Silicon Mac with
128 GB of memory.

16 of 17 catalog profiles passed smoke checks. Gemma 4 12B answers text prompts
but incorrectly identifies a solid red image as black. This also reproduces
with the previous local runtime and the upstream MLX-VLM command-line tool;
the exact cause remains unresolved. Other tested Gemma and Qwen profiles
passed the red-image check. Use another tested vision profile when image
interpretation matters.

The Xcode UI test runner terminated before connecting, so the automated UI
suite did not execute. Native interaction checks were performed separately.
Testing on macOS 14 and lower-memory machines, subjective speech/music
quality review, real-model tool calling, optional MTP acceleration, image
editing, and a full generation-parameter matrix remain outside this run.
